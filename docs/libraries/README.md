# Libraries

Gammasoft has several modern C++ libraries, the most well-known <a href="https://gammasoft71.github.io/xtd/" target="_self">xtd</a>.

## Modern C++ libraries

|                                                                                                           | Project                                                             | Brief                                                                                                                                                                     |
| --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
