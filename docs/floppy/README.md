## Biography

* Name : Floppy
* Nickname : The pixelated friend of the compiler
* Occupation : 
  * Faithful Gammasoft companion since the beginning.  
  * Best friend of <a href="https://gammasoft71.github.io/xtd/" target="_self">xtd</a> developers since... forever.
* Created in : 1999 (Right after Clippy, but with more class)
* Favorite style : Retro pixel + modern C++ = eternal elegance.
* Skills :
  * Memorize your builds.
  * Give style to your logs.
  * Never crash (unless it is launched under Windows ME).
* Personality : Always enthusiastic. A bit sassy when ignored too long.
